#  Jogo da Velha

##  Sobre o Projeto

O **Jogo da Velha** é uma aplicação desktop desenvolvida em **C# utilizando Windows Forms (.NET 8)**, recriando um dos jogos mais conhecidos de forma interativa e intuitiva.

O projeto foi desenvolvido com o objetivo de praticar conceitos de programação orientada a objetos, desenvolvimento de interfaces gráficas (GUI), manipulação de eventos e lógica de programação.

Durante a partida, os jogadores alternam entre os símbolos **X** e **O**, enquanto o sistema verifica automaticamente as condições de vitória, empate e reinício da partida.

---

##  Funcionalidades

* ✅ Interface gráfica desenvolvida com Windows Forms
* ✅ Partidas para dois jogadores no mesmo computador
* ✅ Alternância automática entre os jogadores
* ✅ Verificação automática de vitória
* ✅ Identificação de empate
* ✅ Reinício da partida
* ✅ Atualização da interface em tempo real
* ✅ Código organizado para facilitar futuras melhorias

---

##  Objetivo

O principal objetivo deste projeto foi aplicar conhecimentos em desenvolvimento desktop utilizando C#, explorando a criação de interfaces gráficas e implementando toda a lógica necessária para o funcionamento do jogo.

Além disso, o projeto contribuiu para o aprimoramento da lógica de programação e do uso de eventos em aplicações Windows Forms.

##  Como Jogar

1. Execute a aplicação.
2. O primeiro jogador realiza sua jogada marcando uma posição do tabuleiro.
3. Os jogadores alternam automaticamente entre **X** e **O**.
4. O sistema verifica continuamente se houve vitória ou empate.
5. Ao final da partida, é possível iniciar uma nova rodada.
